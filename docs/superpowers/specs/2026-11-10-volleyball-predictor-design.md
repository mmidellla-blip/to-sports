# V리그 승패·세트스코어 예측기 설계

날짜: 2026-11-10

## 목표

V리그 남자부·여자부 경기의 **승패**와 **세트스코어(3:0 / 3:1 / 3:2 / 2:3 / 1:3 / 0:3)** 확률을 낸다.
농구(`predict.py`)·야구(`predict_kbo.py`) 예측기와 같은 흐름(데이터 수집 → 예측 → 백테스트 → HTML 리포트)을 따른다.

성공 기준
- 팀 두 개 또는 날짜를 주면 승패 확률과 세트스코어 6칸 확률이 나온다.
- 백테스트는 경기 전날까지의 데이터만 쓴다 (미래 정보 누수 없음).
- 백테스트에서 승패 적중률, 로그 손실, 세트스코어 적중, 확률 보정(모델이 70%라 한 경기가 실제 약 70%)을 본다.

범위 밖 (이번에는 안 만듦): 총득점 언더오버, 점수 핸디캡, 선수 결장 보정, 컵대회·포스트시즌.

## 데이터

출처: `https://user-api.kovo.co.kr/stat/game-schedule?seasonCode=XXX&leagueCode=201&size=1000&page=0`

- `seasonCode`: 001 = 2005, 시즌마다 +1 → 021 = 2024-25, 022 = 2025-26, 023 = 2026-27
- `leagueCode` 201 = 정규리그
- 한 시즌 = 남 126 + 여 126 = 252경기, 아직 안 한 경기도 들어 있음 (`score` = "")
- 쓰는 필드: `gdate`, `gender`(1 남 / 2 여), `gnum`, `hcode`/`acode`, `hname`/`aname`,
  `hspoint`/`aspoint`(세트 수), `hs1point`…`hs5point`, `as1point`…`as5point`(세트별 점수), `score`

이미 받아 둔 파일: `kovo_021.json`, `kovo_022.json`, `kovo_023.json`.

## 파일 구성

### `vb_fetch.py` — 수집·변환
- `python vb_fetch.py 023` → `kovo_023.json` 다운로드(요청 사이 1초 쉼) 후 `vb_games.csv` 갱신
- `python vb_fetch.py --from-json kovo_021.json kovo_022.json kovo_023.json` → 받아 둔 JSON만 변환
- 다운로드가 막히면 브라우저 DevTools로 JSON을 저장하는 방법을 안내하고 끝낸다.
- 팀 이름: 팀 코드(`hcode`)로 짧은 이름 표를 둔다 (예: `현대캐피탈`, `대한항공`, `흥국생명`). 표에 없는 코드는 `hname` 그대로 쓴다.

`vb_games.csv` 칸:
```
date,season,gender,gnum,home,away,home_sets,away_sets,h1,h2,h3,h4,h5,a1,a2,a3,a4,a5,played
```
`played` = 1(끝남) / 0(예정). 같은 (season, gender, gnum)은 덮어쓴다.

### `predict_vb.py` — 예측·백테스트
- `python predict_vb.py --home 현대캐피탈 --away 대한항공`
- `python predict_vb.py --date 20261112` → 그날 예정 경기 전부
- `python predict_vb.py --backtest --season 2025-26` → 시즌 백테스트 요약 출력
- 성별은 팀 이름으로 자동 판단. 없는 팀이면 그 성별의 팀 목록을 보여주고 끝낸다.

### `report_vb.py` — HTML 리포트
- `python report_vb.py [--season 2026-27]` → `backtest_vb.html` 저장 후 브라우저로 열기
- 기존 `report.py`의 색·레이아웃 토큰(라이트/다크)을 그대로 쓴다.
- 내용: 요약 숫자(승패 적중률, 로그 손실, 세트스코어 적중), 확률 보정 표, 경기별 카드(6칸 확률 막대 + 실제 결과 표시). 남/여 필터.

### `test_vb.py` — 계산 검증
- 세트 승률: p = 0.5 → 0.5, p와 1−p 대칭, p가 커지면 단조 증가
- 세트스코어 6칸 합 = 1 (SIGMA = 0일 때와 SIGMA > 0일 때 모두)
- SIGMA를 키우면 3:0 + 0:3 확률이 늘어남
- 백테스트가 그 경기 날짜 이후 데이터를 안 쓰는지

## 모델

경기마다 아래 순서로 계산한다.

1. **득점률 레이팅**: 팀의 시즌 랠리 득점률 `s = 딴 점수 / (딴 점수 + 내준 점수)`를 로짓으로 바꿔 `r = log(s/(1−s))`.
   상대 강도 보정: `r_i = logit(s_i) + 상대들 r의 평균`을 몇 번 반복해 수렴시키고, 리그 평균이 0이 되게 맞춘다.
2. **지난 시즌과 섞기**: 지난 시즌 레이팅 × `REGRESS`(평균 쪽으로 끌어당김)를 기본값으로,
   이번 시즌 n경기를 `n/(n+K)`만큼 믿는다. 지난 시즌 기록이 없는 팀(신생 팀)은 기본값 0.
3. **랠리 승률**: `p = sigmoid(SCALE × (r_home − r_away) + HOME)`
4. **세트 승률** (랠리마다 독립 가정, 정확한 식):
   - 1~4세트: 25점 선승, 24:24부터는 2점차 → 듀스 이후 승률 `p² / (p² + q²)`
   - 5세트: 15점 선승, 같은 듀스 규칙
5. **세트스코어** (P = 1~4세트 승률, Q = 1−P, P5 = 5세트 승률):
   - 3:0 = P³, 3:1 = 3P³Q, 3:2 = 6P²Q²·P5
   - 0:3 = Q³, 1:3 = 3Q³P, 2:3 = 6P²Q²·(1−P5)
   - 승 확률 = 3:0 + 3:1 + 3:2
6. **경기 컨디션 흔들림**: 그날 잘되는 팀이 세트를 몰아 따는 효과. 3번의 로짓에 `e ~ 정규분포(0, SIGMA)`를 더한 것으로
   4~5번을 계산해 평균 낸다 (가우스-에르미트 15점 적분). 세트를 독립으로 보면 3:2·2:3을 너무 많이,
   3:0·0:3을 너무 적게 보는 문제를 고친다.

조정값과 시작값 (검증 결과 반영):
- `K` = 8경기 — 이번 시즌 반영 속도
- `REGRESS` = 0.4 — 지난 시즌 레이팅을 40%만 남김 (선수 이동이 많아 시즌 간 연결이 약함)
- `SCALE` = 1.2 — 레이팅 차이 배율
- `SIGMA` = 0.2 — 경기 컨디션 흔들림
- `HOME` = 직전 시즌 홈 랠리 득점률 로짓 (실측 약 +0.007). 시즌마다 홈 승률이 48.8% / 57.9%로 출렁여서
  격자 탐색으로 키우지 않고 데이터 값 그대로 둔다.

남/여는 같은 식, 조정값은 따로 둘 수 있게 한다 (처음에는 같은 값).

**조정 방법**: 조정하는 시즌과 평가하는 시즌을 나눈다.
- 2024-25를 2023-24 기본값으로 백테스트해 조정값(K, REGRESS, SCALE, SIGMA)을 격자 탐색으로 고른다 (기준: 세트스코어 로그 손실).
- 고른 값으로 2025-26을 2024-25 기본값으로 평가한다 (표본 밖 성적).
- 2026-27 진행분은 경기가 쌓일 때마다 확인용으로 본다.
- 2023-24 데이터(`kovo_020.json`)가 없으면 2025-26으로 조정하고 표본 내 결과라고 표시한다.

## 검증 결과 (2026-11-10, 버리는 코드로 확인)

2024-25 기본값 → 2025-26 252경기, 2025-26에서 조정 (표본 내라 실제보다 약간 좋게 나옴).

| 항목 | 모델 | 비교 기준 |
|---|---|---|
| 승패 적중 | 61.5% | 동전 50% / 무조건 홈 57.9% |
| 승패 로그 손실 | 0.657 | 동전 0.693 |
| 세트스코어 1순위 적중 | 25.4% | 지난 시즌 비율만 17.9% |
| 세트스코어 로그 손실 | 1.767 → SIGMA 추가 후 1.737 | 지난 시즌 비율만 1.779 |

- 남자부(승패 63.5%)가 여자부(59.5%)보다 잘 맞음
- 확률 보정: 50~60% 구간 실제 55.6%, 60~70% 구간 실제 67.8% — 약간 조심스러운 편
- 2026-27 진행분 16경기는 표본이 너무 작아 판단 보류

## 출력 예시

```
=== 현대캐피탈 (홈) vs 대한항공 (원정) · 남자부 ===
[현대캐피탈] 지난시즌 득점률 52.1% / 이번시즌 4경기 (반영 33%) → 레이팅 +0.071
[대한항공]   지난시즌 득점률 51.4% / 이번시즌 5경기 (반영 38%) → 레이팅 +0.043
랠리 승률(홈): 51.2%  →  세트 승률 56.0% (5세트 54.6%)

승패       : 현대캐피탈 승 61% / 대한항공 승 39%
세트스코어 : 3:0 18% / 3:1 23% / 3:2 20% / 2:3 17% / 1:3 14% / 0:3 8%
```

## 오류 처리

- 팀 이름이 틀림 → 그 성별 팀 목록을 보여주고 끝냄
- `--date` 날에 경기 없음 → "경기 없음"
- 지난 시즌 파일 없음 → 모든 팀 기본값 0, 경고 한 줄
- 세트별 점수가 비어 있는 끝난 경기 → 세트 수만 쓰고 득점률 계산에서는 빼고, 경고 한 줄
